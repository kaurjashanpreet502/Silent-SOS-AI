## 📌 Problem Statement

In emergency situations like accidents, falls, or unsafe conditions, a person may not always be able to manually call for help or share their location.

Many times, delayed response can increase the risk to a person's safety.

Our aim is to create a simple AI-based safety assistant that can detect possible danger situations and help in sending emergency alerts.


## 💡 Our Solution

Silent SOS AI is an AI-powered emergency assistance prototype that monitors unusual activities and detects possible risk situations.

When suspicious activity is detected, the system simulates an automatic SOS response by showing:
* Emergency risk level
* Movement status
* Battery status
* AI confidence level
* Location sharing
* Emergency message preview

The main goal is to provide quick assistance when a person is unable to manually ask for help.


## ✨ Key Features

### 🛡️ Protection Activation
- User can activate the safety monitoring system.

### 🏃 Sudden Running Detection
- Detects suspicious movement patterns.

### ⚠️ Risk Prediction
- Shows emergency risk level based on detected activity.

### 🧍 Movement Monitoring
- Checks if movement stops after a possible fall.

### 📍 Location Sharing
- Generates a live location link for emergency response.

### 🔋 Battery Status
- Displays available battery level to estimate response time.

### 📞 Emergency Contact
- User can add an emergency contact for alerts.

### 🤖 AI Confidence
- Displays AI prediction confidence score.


## 🔄 Working Flow

1. User activates Silent SOS AI.
2. System starts monitoring activity.
3. Suspicious activity is detected.
4. Fall and movement status are checked.
5. Risk level is updated.
6. Emergency alert information is generated with location and battery details.
